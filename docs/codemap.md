# Code map

Generated by `scripts/codemap.py` from each Go package's own doc comment.
Do not edit it by hand: fix the package's doc comment and run the script
again. CI fails while this file is out of date.

| Package | What it is |
|---|---|
| `cmd/m0demo` | Command m0demo is milestone M0: prove the data plane and socket sharing. |
| `cmd/s3topics` | Command s3topics is spike S3: verify that rotating the rendezvous topic keeps every epoch on the SAME shard. |
| `cmd/shrooms` | Command shrooms is the mesh daemon and CLI. |
| `cmd/shrooms-agent` | Command shrooms-agent runs this machine's coding-agent sessions (Claude Code, pi) and serves them to its user here and to the owner's other devices over the mesh (docs/agents.md). |
| `cmd/shrooms-relay` | Command shrooms-relay forwards packets for meshes it is not a member of. |
| `cmd/wakuspike` | Command wakuspike is spike S1: prove that a Go process can drive liblogosdelivery via cgo, join a Waku network, and complete a publish -> receive round trip through the event callback. |
| `internal/agent` | Package agent runs coding-agent sessions — Claude Code, pi, and other harnesses (harness.go) — and serves them to the owner's other devices over the mesh (docs/agents.md). |
| `internal/control` | Package control defines the mesh control-plane messages carried over Waku. |
| `internal/cred` | Package cred separates authority from participation. |
| `internal/ctrl` | Package ctrl is the framing that lets control traffic share the WireGuard socket. |
| `internal/disco` | Package disco is the socket-level discovery protocol: small authenticated probes sent over the same UDP socket as WireGuard, used to find which of a peer's candidate endpoints actually works. |
| `internal/dns` | Package dns serves names for the mesh and nothing else. |
| `internal/hosts` | Package hosts renders and applies /etc/hosts entries for mesh peers. |
| `internal/identity` | Package identity holds device keys, the mesh network key, and the derived addressing scheme. |
| `internal/invite` | Package invite implements one-time enrolment tokens (ADR-017). |
| `internal/keycard` | Package keycard drives a Keycard: pairing, the secure channel, the PIN, and signing at this project's own derivation path (ADR-022). |
| `internal/listeners` | Package listeners finds what is listening on this device's mesh addresses. |
| `internal/logtail` | Package logtail keeps the last few hundred log lines in memory so a UI can show them. |
| `internal/memstat` | Package memstat says where a shrooms process's memory goes. |
| `internal/mesh` | Package mesh wires Waku discovery to the WireGuard data plane. |
| `internal/portmap` | Package portmap asks the local router to open an inbound UDP port, so that a node behind a home NAT can be dialled directly instead of paying for a relay. |
| `internal/relay` | Package relay carries WireGuard traffic between peers that cannot reach each other directly. |
| `internal/rendezvous` | Package rendezvous adapts a Logos Delivery node to the interfaces the protocol packages define. |
| `internal/service` | Package service publishes local ports on the mesh under their own names. |
| `internal/state` | Package state handles on-disk configuration and persistent device state. |
| `internal/topic` | Package topic derives the mesh's rotating rendezvous content topics. |
| `internal/v4` | Package v4 gives every peer a synthetic IPv4 address (ADR-021). |
| `internal/waku` | Package waku is a cgo binding over liblogosdelivery (Logos Delivery / Waku). |
| `internal/wg` | Package wg embeds wireguard-go and shares its UDP socket with our control protocol. |
| `mobile` | Package mobile is the Kotlin-facing surface of the mesh, bound with `gomobile bind`. |
